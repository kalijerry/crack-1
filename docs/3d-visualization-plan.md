# 3D 可视化：规划与进度

目的有两个：**看得懂**（采集到哪了、磁场长什么样、定位准不准）和**验得出**（地图和实物对不对得上）。

## 第一期：3D 门店视图（已做）

App「地磁定位」页右上角的 **3D** 按钮，在 2D 画布和立体视图之间切换。

| 内容 | 说明 |
|---|---|
| 地板、实物货架 | 只有标准货架（`Shelf-001…100`，1223 个）立起来，默认 1.8 m 高，「地图点位」页可以调 0.8～3 m（地图里没有高度数据）。虚拟货架和非标准编码不画 |
| 通道采集进度 | 与 2D 一致：采过的段是半透明绿带；中间绿色实线 = 孤立的一段，黑色虚线 = 已和别的路段关联；没采的是淡细线 |
| 磁场热力图 | 贴在地板上，蓝 = 弱、红 = 强，只画有数据的格子 |
| 点位、当前位置、轨迹 | 点位是橙色立柱；当前位置是蓝色人形加不确定度圆环；轨迹是蓝色带 |
| 视角 | **跟随**（在人身后偏上方）、**总览**（斜上方看全场）、**俯视**。非跟随视角下单指转、双指缩放 / 平移 |

实现：`Store3DScene`（SceneKit，不依赖 UIKit，所以能在 Mac 上离屏渲染做回归检查）、`Store3DView`（SwiftUI 封装）。
货架合并成一个几何体，一次绘制；采集进度最多每秒重建一次。

**限制**：立体视图里不能长按定点、双击设朝向，这些仍在 2D 里做。

## 第二期：AR 叠加（验证地图和实物）

在建图采集 / 实时定位时，用摄像头画面叠加：
- 把地图里的**实物货架**画成半透明线框，立在你看到的真实货架上；
- 把已走过的路径画成地面上的绿色带；
- 每个路口、点位竖一根标。

用途：一眼看出地图坐标和实物偏了多少（货架偏移、通道位置、旋转角）。偏移很明显时，在现场就能发现，不用等回电脑分析。
依赖：视觉里程计已对齐（`VisualOdometryAligner`），把地图坐标换到 ARKit 坐标，再用 `ARSCNView` 画。

## 第三期：LiDAR 实景（可选）

- 打开 ARKit 场景重建，把走过的通道扫成网格，导出 USDZ / PLY 到电脑看；
- 从网格量出**真实货架高度**，回填给 3D 视图和激光雷达射线投射；
- 和地图货架做叠合比较，自动给出每个货架的偏移量。
代价：数据量大、耗电发热；只在建图时开。

## 为什么先做第一期
不需要新的传感器数据，也不影响定位，风险低，并且能立刻让你在手机上看清「走到哪了、哪些线连起来了、磁场长什么样」。
第二期是真正验证地图的工具，建议在你用第一期走过一次现场之后再做，到时候根据你看到的偏差决定叠加哪些内容。
