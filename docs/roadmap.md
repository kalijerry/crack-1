## 阶段 2：减少重复采集
- [x] 增量建图：磁场每格统计 + 蓝牙累积 + 已包含会话存在地图工作区（build-state.json），「追加新会话」只处理新的，旧会话删了不影响
- [x] 价签过滤：厂商 ID 0x000D + 4 字节编号；可导入价签名单（门店导出的 ID 列表，1266 店 23995 个，实测采到的 99.7% 在名单里）；「到哪儿都听得到」（强信号位置标准差 > 15 m）的不当价签
- [x] 采集路线规划：按通道宽度拆走线，涂色算完成度，下一段 = 最近的没涂完的走线（橙色箭头），显示剩余 km 和分钟（全店 324 段、6.8 km、约 113 分钟）
- [ ] 价签位置从价签数据推出：需要「价签 → 货架」的对应表（现有名单只有 ID，没有位置）
- [ ] （分析）双向采集是否必要：等有双向数据

## 阶段 3：提高精度（每项都用 hpass-eval 验证）
- [ ] 三维磁场向量（视觉里程计给出地图系朝向，用东 / 北 / 上三个分量）：要先在真机上标定「设备坐标 → ARKit 相机坐标」，放到真机验证之后
- [x] 高斯过程插值（局部，最近 12 个有数据格）代替反距离补齐，默认开。留出法（藏 20% 有数据的格子再补）：误差中位 0.44→0.36 µT、0.62→0.46 µT（好 18～26%），预测的不确定度也更准；现有测试会话都走在有数据的格子上，定位结果不变，要等走不同走线的测试会话才看得出来
- 固定延迟平滑（显示）和前后向平滑（建图）
- [x] 蓝牙辅助（BLEAssist，手机和回放共用）：听到的强价签大多不在指纹里 → 判「不在采集区域」，禁止地磁收敛；已定到但蓝牙连续 6 秒离得很远 → 判错重找。实测人在没采过的区域时「自信地定错」的点少 50%～89%、跳点 6→1～3 次，正常区域精度不变
- 门店视觉锚点（入口 / 收银台）；LiDAR 横向约束评估后再开

## 阶段 4：长期维护
- [x] 变化检测（LiveFieldMonitor）：有把握的定位时，按 1 m 块累积「读数 − 地图」的带符号偏差；某块攒够 8 个读数、某个特征平均偏差超过 max(2 µT, 地图标准差) → 标成「可能变了」（地图上橙色方块），建议补采。模拟：没变时 0 误报；一段 10 m 偏 6 µT，正好标出那 10 块
- [x] 定位即采集（先只记录）：同一份累积也和磁场图比，显示「定位攒的磁场和地图平均差多少」；先看几次真实数据，差得小再做并入

## 2026-10-07 第一次跨会话评估（服务器上的 091813 + 10-06 的 114810，同一片通道）

- 自己考自己的数字（中位 25～55 cm）太乐观：**用一次的图测另一次，中位 3～8 m**。
- 原因：同一处两次采集的磁场「起伏」很像（|B| 相关 0.78），但**整体水平差 10～16 µT**（|B| −12、Bz +16 µT），远大于磁场自身的起伏（标准差 2.4 µT）。两次的磁力计偏置估计在 x 轴差 7.7 µT；iOS 校准后的磁场更差（差 16～17 µT、相关 0.47）。竖直分量差得最多，怀疑和拿手机的姿势有关，要受控数据确认。
- 已做：
  - 建图时**会话偏移对齐**：新会话和已有数据有 ≥ 20 个共同格子时，先减去整体偏移再累积（生成时会提示偏了多少）；
  - 定位**混合模式**（默认开）：没定到时按起伏找，定到后估出这次的偏移、按绝对值比并慢慢跟踪；
  - hpass-eval：`--runs N`（粒子滤波随机性大，单次不可信）、「只看建图覆盖到的地方」。
- 结果（每项 5～7 次的中位）：同会话 P90 258→131 cm、87→71 cm，首次定位 7→4 m、5→3 m；跨会话一组 6.5→2.5 m，另一组 3.3→5.5 m（重叠太少，结论不稳）。

### 下次采集（受控，用来定结论）
1. 选 1、2 号两条通道，**同一种拿法**（竖着、屏幕朝上微斜，全程不换手）。
2. 每条通道来回走 **3 趟**（去程一边、回程另一边），共 3 个会话：2 个建图、1 个测试（打开「这次是测试会话」）。
3. 开始前原地慢慢转一圈（让偏置估计稳定），结束后上传后台。
4. 另外拿法换成「平放」再走 1 趟测试会话，看姿势对偏移的影响。

## 云端地图（2026-10-07）

- 采集的手机生成磁场图后自动打包上传（「门店数据 → 云端地图」也能手动上传）：地图 JSON + 磁场（只存有数据的格，0.01 µT 量化）+ 蓝牙价签位置 + 房间视觉特征地图，zlib 压缩。实测当前数据（2631 格、1749 个价签、全店地图）107 KB，全店采满估计 0.5～1 MB。
- 别的手机在「门店数据 → 云端地图」下载；本机已有的地图云端更新了，打开页面时自动更新。版本 = 生成时间，旧版本不能覆盖新版本。
- 定位在手机上算，不需要一直联网；没网时用本机已有的版本。
