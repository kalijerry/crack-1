# 办公室携带方式测试（双机协议）

目的：在真实办公室里量「终端用户不用摄像头、手机随便怎么带」时的定位成绩，按携带方式、地图年龄分开报。
真值来自同一个人手上的第二台 iPhone（ARKit），被测手机全程不开摄像头。

- **A = 盲测机**：被测手机。App「设置 → 诊断 → 双机测试 → 盲测机 A」。摄像头强制关，按被测携带方式带着走。
- **B = 伴随真值机**：同一个人竖着拿在胸前。App「设置 → 诊断 → 双机测试 → 伴随真值机 B」。跑 ARKit（建图采集的测试会话），
  广播配对编号，踩到地贴时在地图上长按一下（不用停步）。

一个人就能做。下面的数字（地贴数量、段数、门槛）都是起始建议，首批数据出来后再调。

---

## 0. 一次性准备（1～2 天）

### 0.1 设备

| 项 | 要求 |
|---|---|
| A | 被测 iPhone。不要磁吸壳 / MagSafe 钱包（磁吸附件是设备系的强偏置，会让地磁特征整体失真；终端用户的这种情况另测，见第 6 节） |
| B | 第二台 iPhone，最好带激光雷达（ARKit 更稳）。同样不要磁吸附件 |
| 两台都要 | 装同一版本 App；「设置 → 云端连接」连上（结束后自动上传）；「设置 → 定位 → 锁屏后继续定位」打开；位置权限选「使用 App 期间」；蓝牙权限允许 |

### 0.2 地图

1. 用房间扫描做**带房间（units）和门（MapDoor）**的多房间地图。没有 units / 门的旧地图算不了房间判对率，需要重扫一次。
2. 按 [office-test.md](office-test.md) 第 2～4 步采集建图会话（≥ 3 段，手持）并云端融合，下载融合后的地图。
3. 之后各测试日**不重建地图**，这样才能量「地图老化」。

### 0.3 地贴（真值审计点）

- 贴 25～40 个编号地贴：每扇门两侧各 1、每个工位区中心 1、走廊交叉口 1。
- 用 B 在建图页长按登记每个地贴的位置（坐标只留在私有地图里，不进公开仓库）。
- 地贴只给 B 当重锚点和真值审计点，被测者不需要停步。

### 0.4 杆臂

A 在被测位置（裤兜、手里、包里）时，与 B（胸前竖持）的水平距离大约 0.25 m。B 的页面上可以改，写进 meta，事后还能改。

## 1. 携带方式（每天每种 2 段）

| 代号 | 怎么带 | 说明 |
|---|---|---|
| `texting` | 手里拿着，边走边看屏 | 最接近现在的用法 |
| `pocket_front` | 前裤兜，屏幕朝腿 | 坐下 / 起身也在兜里 |
| `hand_swing` | 手握手机，自然摆臂 | 最难的一种 |
| `calling` | 贴耳打电话的姿势（可以不真打） | 左右耳都要有 |
| `bag` | 电脑包 / 挎包 | 记下包里有没有笔记本电脑（磁干扰） |
| `mixed` | 中途切换 2～3 次 | 每次切换在 B 上点「记一次切换」 |

背包、外套口袋、后裤兜暂不纳入 v1；要加就多一组采集和标定。

另外两个开关要分开记、不要混在同一段里：

- **锁屏**：口袋 / 包里的段，每种携带方式至少有一段按侧键锁屏（`route` 选「其他」或在备注里写「锁屏」）。真实用户会锁屏，
  没锁屏的成绩说明不了锁屏后的表现。蓝牙标签只在 App 前台扫描，锁屏段的冷启动没有蓝牙先验。
- **按携带方式调整**（设置 → 定位，默认开）：A 上开着时离线回放要加 `--carry-motion`；想和老行为对比，同一路线关掉再走一段
  （meta 的 `carry_motion` 记了当时的状态）。

## 2. 路线（固定，便于跨版本比较）

| 代号 | 内容 | 长度 |
|---|---|---|
| R1 | 走廊环线，穿过 3 个房间，6 次过门 | 约 80 m |
| R2 | 工位到工位，中途 3 次坐下 30 s 再起身 | 约 60 m |
| R3 | 混合路线 + 原地转身 + 停 10 s + 倒退 2～3 步 | 约 80 m |

每段 8～12 分钟（一条路线可以走 2～3 圈）。

## 3. 测试日

D0（建图当天）、D+1、D+7、D+30，以及**家具搬动后的第二天**。每天约 12 段（6 种携带方式 × 2），2～3 小时。

多人、多机：至少 3～5 个人当被测者、≥ 2 个 iPhone 机型。步长、携带方式分类阈值都和人有关，要按人留出验证。

---

## 4. 每一段的步骤

1. **B 先开始**：双机测试 → 伴随真值机 B → 「开始伴随真值」。App 会切到「建图」页：
   - 在起点长按定点、设朝向（和平时建图一样）；
   - 记下页面上的**配对编号**（8 位，例如 `3F9A1C07`），B 会通过蓝牙广播它。
2. **A 开始**：双机测试 → 盲测机 A → 选携带方式、路线 → 「开始盲测录制」。
   - A 会自动扫到 B 的配对编号（页面显示「蓝牙扫到」）；扫不到就在开始前手动输入编号。
   - 摄像头全程关闭；页面显示「检测到敲击」次数。
   - 起点（可选）：知道起点时可以切到 A 的「导航」页长按起点并设朝向；不设也行，离线会分别按「已知起点」和「冷启动」各评一次。
3. **开始对时**：两台手机屏幕朝上叠在一起，平放在桌面上，**一起敲三下**（间隔约 0.5 s，力度像敲门）；
   然后两机贴紧拿在手里**一起转 2～3 秒**（左右来回转，用陀螺互相关对时，比敲击更稳）。看两台的「检测到敲击」都 +3。
4. **A 放进被测携带方式**（口袋 / 包 / 摆臂……）。口袋里屏幕会自动熄灭；直接按侧键锁屏也可以，定位继续跑（状态栏有定位图标）。
5. **走路线**。B 竖着拿在胸前：
   - 每踩到一个地贴，在 B 的地图上长按那个地贴（不停步）；
   - `mixed`：A 每换一次携带方式，在 B 的双机测试页点「记一次切换」（能拿到 A 时也可以在 A 上选新方式）。
6. **结束对时**：拿出 A，两机再叠在一起敲三下、一起转 2～3 秒。
7. **先停 A，再停 B**：A 点「结束」，B 点「结束」（或在建图页结束）。两台连着云端时会自动上传。

### 盲测段作废条件

- A 的 `track.csv` 里 `src` 不是全 `pdr`（不应出现，出现说明版本不对）；
- B 的 ARKit 跟踪长时间不正常、重定位跳变 > 0.5 m 的片段；
- 地贴处的真值残差 > 0.5 m 的段；
- 开始或结束的三下敲击有一台没检测到，且转动对时也失败。

## 5. 要上传 / 拷出的东西

连着云端时两台都会自动上传。离线时用「设置 → 诊断 → 数据管理」导出：

| 手机 | 目录 | 关键文件 |
|---|---|---|
| A | `mag-tracks/mag_<时间>_files/` | `meta.json`（`purpose: blind_test`、`camera: false`、`carry_mode`、`pair_id`、`bumps_ms`、`mode_switches`、电量和发热）、`imu.csv`（v4：真四元数 + 重力列）、`mag_raw.csv`、`acc_raw.csv`（100 Hz，对时用）、`ble.csv`、`track.csv` |
| B | `sessions/ios_survey_<时间>/` | `meta.json`（`role: gt_companion`、`pair_id`、`lever_arm_cm`、`bumps_ms`、`mode_switch_marks_ms`）、`arkit_pose.csv`、`anchors.csv`（地贴修正）、`imu.csv`、`acc_raw.csv` |

另外每天记一行：日期桶（D0 / D+1 / …）、被测者代号、机型、有没有家具搬动。**不要**把坐标、房间名、日期写进公开仓库；
报告只按（站点代号、携带方式、地图年龄桶）聚合。

## 6. 离线处理（概要）

1. 按 `pair_id` 把 A、B 两段配成一对；
2. 对时：两机 `acc_raw.csv` 的敲击峰互相关求时钟偏移，再用开始 / 结束两组解出漂移；转动段的陀螺互相关做细对齐；残差 > 20 ms 的段弃用；
3. 真值：B 的 ARKit 轨迹按地贴对齐到地图（`tools/magmap.py --truth-dir`），减去杆臂，按对好的时钟写成 A 的 `truth.csv`；
4. 回放 A 的 `imu.csv` / `mag_raw.csv`（真实计步路径），已知起点和冷启动各评一次；
5. 指标：房间判对率（有定位时 / 全部时间）、错房间（相邻 / 远处）、过门延迟、≤ 1 m 占比、P50 / P90、覆盖、首次正确定位的时间和路程、
   首次正确前的错定次数，按携带方式和地图年龄分桶。真值底噪约 0.3～0.5 m，版本之间只比差值。

## 7. 附加实验（Stage 1 之前做一次）

- **两个高度**：A 放裤兜、另一台同型号手机手持，同时走同一路线（各录一段盲测），比较两者和地图的磁场残差。
  口袋高度（≈ 0.8 m）正好在钢制桌架、抽屉柜那一层，若梯度差明显，就要考虑双高度建图或按携带类别分图。
- **磁污染**：同一路线分别在 A 装 MagSafe 钱包 / 磁吸壳、口袋里放钥匙、包里放笔记本电脑时各走一段（携带方式照常选，
  在 B 的备注里写明附件），用来定「磁场不可信 → 降级成只靠计步 + 地图」的检测门限。

## 8. 待标定的参数

下列参数现在都是占位值，**待自采 iPhone 双机数据标定**，不能用任何不可商用数据集的数字：

- 各携带方式的步长系数、航向噪声、地磁特征权重；
- 携带方式分类阈值；
- 手机-行走方向夹角的先验（`calling` 是 ±90° 两种可能，不是 0°）；
- 盲测敲击在线检测门限（现为 2.5 g，只作核对）、杆臂默认值（0.25 m）。

## 9. 耗电与权限说明

- 锁屏后继续定位靠 iOS 的后台定位模式：定位期间开一个最低精度（3 km 级，只用基站 / Wi-Fi）的系统定位让 App 保持运行，
  不读取、不保存经纬度；状态栏会显示定位图标，结束定位后立即停止。可在「设置 → 定位」关掉（关掉后锁屏定位会停）。
- 耗电主要来自 50 Hz 运动传感器、100 Hz 磁力计和粒子滤波。每段盲测的 `meta.json` 记录了开始 / 结束电量和发热状态，
  首批数据出来后在这里补上每小时耗电。
- 盲测时打开了距离传感器：放口袋 / 贴耳时屏幕自动熄灭，App 仍在前台，比锁屏更稳。
