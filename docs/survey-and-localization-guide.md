# 建图采集与地磁定位：操作流程

对应的规划见 [oriient-benchmark-plan.md](oriient-benchmark-plan.md)。这里只写「怎么做」。

## 0. 准备

1. 云编译出 ipa，用 Sideloadly 装到 16 Pro（见 [sideload.md](sideload.md)）。**首次打开「建图采集」会请求摄像头权限**，只用于 ARKit 视觉里程计，不保存画面。
2. 手机配置：**不带磁吸壳、不装磁吸支架**，每次采集前在「备注」里写明配置、手持姿态、营业状态。
3. App 的「门店数据」页导入 `map.json`（货架和通道，带信封也可以）。

## 1. 建图采集（现场）

「地磁定位」页 → **建图采集**：

1. 点「开始建图采集」。手机竖着拿，摄像头朝前下方，像 AR 那样。
2. 站在一个路口或已知点：**长按地图**（离路点 / 点位 60 cm 内会自动吸附）。
3. **双击地图**，在地图上点或拖动，让橙色箭头指向你要走的方向，再双击确定。
4. 朝箭头方向直线走 1.5 m，App 自动把 ARKit 轨迹对齐到地图。
5. 沿通道走。**每走约 30 m，或到路口，长按地图修正一次**。屏幕上「距上次修正」超过 30 m 会提醒。
6. 要换方向时双击重设朝向。
> **自动贴通道（实时）**：采集时默认开。沿通道直走 4 m 以上、方向和通道差 12° 以内，就把 ARKit 的朝向一点点转回通道方向；横向只在轨迹跑出通道时才往回拉（人不一定走正中，硬拉中心线反而有偏差）。路口拐弯、横穿时不动。对着真值回放（只有起点和朝向、不长按修正）：
>
> | ARKit 朝向漂移 | 不贴：中位 / P90 | 贴：中位 / P90 |
> |---|---|---|
> | 0 | 35 / 57 cm | 23 / 32 cm |
> | 10°/分钟 | 52 / 185 cm | 28 / 39 cm |
> | 20°/分钟 | 119 / 355 cm | 41 / 55 cm |
>
> 所以开着它，途中基本不用长按修正。状态区会显示步行速度和采样率（超过 1.6 m/s、或采样率低于 50 Hz 的那段不算进度），以及「最近没采完」的通道，按它走就不会漏。离线生成磁场图时默认不再跑这一步：离线已经有分段贴通道，两个叠在一起在漂移小时反而更差。

> **自动定位起点**：已经生成过磁场图的区域，开始采集后可以点「自动定位起点」，不用长按、不用设朝向，直接沿采集过的通道走。地磁定到、并且连续走了 5 m 都对得上之后，自动设好起点和 ARKit 的旋转（震动提示），锚点文件里写 `start`（备注「自动起点」）和 `align`（旋转 φ），生成磁场图时直接用。用真实会话回放：走 11 m 定到，位置差 49 cm、旋转差 2°。新区域还是要长按定起点。
>
> **同时测地磁定位精度**：开始采集前打开这个开关（需要已有磁场图），采集时后台跑一个冷启动的地磁定位，用采集轨迹（ARKit + 贴通道）当参考，状态区实时显示中位 / P90 / ≤1 m 比例 / 跳点次数 / 首次定位走了多远，逐点结果写进会话目录的 `shadow_loc.csv`。要测得准：用「长按」定起点（不要用自动起点，否则参考本身来自地磁），而且这次采集不要拿去生成磁场图（否则是自己考自己）。
>
> **AR 叠加**：现在跟着地图上显示的位置走（地磁修正了位置，AR 里的货架线框也一起挪）；「自动定位」（不知道朝向）时，定位成功并走出 3 m 后也能显示 AR；地磁没把握时 AR 隐藏，免得叠错位置。

> **涂色式采集进度（参考 Oriient）**：采集页「采集进度」默认显示「涂色」。采集时以你为圆心画一个 40 cm 的绿圈，走过的地方按 25 cm 一格涂上颜色：淡灰 = 通道里还没涂到，浅绿 = 走过一趟，深绿 = 两趟以上（同一趟反复经过只算一次，走开 3 m 再回来才算新的一趟）。走太快、采样率低时不涂。状态区显示当前通道涂了百分之几，「采集进度」显示全场涂了多少 m²。目标是把整条通道的**宽度**涂满：靠近钢货架，横向挪半米磁场就差好几 µT，只走中间一条线，顾客贴边走时就对不上图。宽通道（> 1.5 m）贴左右两边各走一趟。可以随时切回「方向」视图看每米两个方向走没走。涂色存在 `Documents/survey-paint.bin`，「清空采集进度」一起清。
>
> **涂色引导**：采集时地图上有两样引导：**橙色圈 + 虚线**指向离你最近（30 m 内）还没涂的地方；当前通道宽于 1 m 时画**绿色虚线**建议走线：去程贴一边、回程贴另一边（正好两个方向也都有了），宽于 1.6 m 时中间再走一趟。生成磁场图时，用周围数据补出来的格子离真实数据越远越不可信（50 cm 处标准差放大 1.5 倍，150 cm 处 2.5 倍），定位时不会被「猜出来」的格子带偏。

> **删除磁场图**：「生成磁场图（手机上）」里显示当前在用的磁场图是哪些会话、什么时候生成的；点「删除当前磁场图」就去掉。下面勾选会话只决定下次生成用哪些，不会改已经在用的图。

> **长直通道建图（2026-10-06 现场问题）**：沿 124 m 主通道走一趟，ARKit 朝向和地图差约 5°，旧的生成算法每 10 m 独立修正、平移有上限，修不回来，末端横向偏了 11 m，磁场数据被画到货架里，用这张图定位就会到处乱飘。现在：生成时先按顺序累积修朝向（和采集时的自动贴通道一样）；贴通道只认和行进方向一致的通道（不被横穿的货架通道吸走）；人在通道里偏左偏右不算误差、只把出界的拉回来；绕开推车这类横移一次最多转 1.5°，并且优先沿着当前通道走。**升级后要用原来的会话重新生成一次磁场图。** 定位时 LiDAR 深度默认「只记录」，不参与定位。

> **货架和现场对不上（整体偏了）**：切到 3D，点右上角「校准」，视角自动变成俯视。用底部方向键按地图方向整体挪货架（步长 5 / 10 / 50 cm），立刻能看到效果；通道不动。偏移存在手机上，2D、3D、AR 叠加和深度测距都用调过的位置。点「完成」记一条日志，地图页可以看到当前偏移和归零。

7. 地图上通道的线是采集进度（采集页有图例）：
   - **淡灰细线**：还没走；
   - **橙色**：只走了一个方向，要反方向再走一遍；
   - **绿带 + 绿色实线**：双向采完，还是孤立的一段；
   - **绿带 + 黑色虚线**：双向采完，已经和别的路段通过路口关联起来。全场采完、连通之后，所有线都会变成黑色虚线。
   **每条通道要双向各走一遍**：只采一个方向的通道，反方向走时定位容易跳（实测第二条通道就是这样）。
8. 点「结束采集」。会话在「采集 → 历史会话」里，导出后拷到电脑。

要点：

- ARKit 状态变成「受限」时位置不更新，也不计入覆盖。放慢速度、对准有纹理的地方，必要时回到最近的路口重新长按。
- 不要在 ARKit 受限的时候继续走很远再修正，那段数据会被丢掉。
- 货架通道纹理重复，ARKit 容易漂。修正得越勤，建出来的图越准。

## 2. 建磁场图（电脑）

```bash
python tools/magmap.py --map map.json --sessions 会话1 会话2 ... --out magmap.json \
    --truth-dir truth --report report.json
```

看终端输出的质检：

- 每个会话每一段的「比例」应在 0.97～1.03；超出 0.9～1.1 的段会被丢弃，说明锚点点错了或 ARKit 出了问题。
- 「终点残差」是锚点之间累积的漂移，几十厘米以内正常。
- 通道覆盖最差的几条，回去补走。
- 「最容易认错的平行通道对」分数越小越像。这些通道要特别评测。

## 3. 导入并定位

1. 把 `magmap.json` 传到手机，「地磁定位」页 → 地图点位 → **导入地图 JSON**。
2. **实时定位**页：
   - 打开传感器，磁场精度画 8 字到「高」。
   - 已知位置：长按地图定点、双击设朝向、走。首次设朝向会记住「地图朝向」。
   - 不知道在哪：点「自动定位」，沿通道直行 20～30 m，收敛后出现蓝点。需要磁场地图和上面记住的地图朝向。
   - 打开「地磁纠偏」才会用磁场图纠正惯导；关闭时只有惯导 + 通道约束，可用来对照。
3. 走到确定的位置长按地图修正，「修正记录」会记下修正前偏了多少。每次定位的轨迹存在 `mag-tracks/` 里。

## 4. 离线回放（调参）

```bash
cd ios/HPASSKit
swift run hpass-replay --session 会话目录 --map map.json --truth truth/会话名.csv \
    --magmap magmap.json [--cold] [--out replay.csv]
```

输出惯导和地磁滤波相对位置真值的误差（中位、P90、最大、最后），冷启动时还输出收敛用了多久。
改算法参数后不用进店，直接用已采的会话重跑。

## 5. 视觉里程计与激光雷达（实时定位页）

实时定位页开始前有三个开关：

- **视觉里程计**：定点、设好朝向之后启动摄像头和 ARKit，位移由它给，不再靠计步。手机**竖着拿、摄像头朝前**。朝设定方向直走 1.5 m 后自动对齐到地图；跟踪变差时自动退回计步，恢复后重新对齐。
- **激光雷达测货架距离**：`关` / `只记录` / `参与定位`。
  - 默认是**只记录**：每秒约 10 次，把深度图换算成「左右两侧货架离我多远」，存到 `mag-tracks/<会话>_files/depth_lateral.csv`，**不影响定位**。
  - 这条换算在真机上还没验证过。用 `hpass-replay --depth` 核对（见下）之后，误差合理再切到「参与定位」。
- **用计步器的距离校正步长**：默认关。页面上始终显示「计步器 / 惯导距离」的比值，供你判断。

核对激光雷达（需要建图采集会话 + 真值，`depth_lateral.csv` 在建图采集会话里自动录）：

```bash
swift run hpass-replay --session 会话目录 --map map.json --truth truth/会话名.csv \
    --depth 会话目录/depth_lateral.csv
```

输出左 / 右侧距离、通道净宽相对地图货架的误差。中位误差在 30 cm 以内再考虑打开「参与定位」。

## 6. 只走几条通道：导出 → 电脑建图 → 导回 App

不需要一次采完全场。走几条通道也可以建出一张「局部磁场图」，在这几条通道里定位、导航；以后再补走别的通道，重建时把所有会话一起给脚本。

1. **采集**：「建图采集」里走你要的通道（每条双向各走一遍）。结束后页面下方出现「导出给电脑建图」，点「打包」再「导出这次会话（zip）」，用隔空投送发到电脑。
2. **建图（电脑）**：

   ```bash
   python tools/magmap.py --map map.json --sessions 会话1.zip 会话2.zip ... --out magmap.json \
       --truth-dir truth --report report.json
   ```

   看终端里的质检：每一段的比例应在 0.97～1.03；通道覆盖里你走的那几条应在 85% 以上。
   **以后补走了新通道，重新跑时要把之前所有的会话一起给它**（脚本每次都从原始数据重建，不叠加旧的 magmap.json）。
3. **导回**：把 `magmap.json` 传到手机，「地图点位」页 →「导入地图 JSON」。
   - 会替换 App 里已有的磁场数据；货架和通道不变；你放的点位会保留。
   - 导入后「实时定位」里「地磁纠偏」可以打开，「自动定位」可以用。
4. **注意范围**：磁场图只覆盖你走过的通道（外加周围约 1.5 m 的插值）。在这个范围里定位和冷启动正常；**走到没采过的通道，地磁没有数据可比，会把位置往已采的通道上拉**。局部建图时，请只在已采的通道里测试。
5. **回放调参**：同一份会话和 `truth/` 里的真值可以给 `hpass-replay` 重跑，见第 4 节。

## 7. 磁场来源：原始磁力计减固定偏置（默认）

iOS 的「校准后磁场」会跟着系统自己的偏置估计漂移（实测一分钟内 0.6～3.75 µT，偶尔跳一下），同一个位置不同时刻读数不同。
现在建图和实时定位都改用 **原始磁力计 − 这次的偏置中位数**：

- `tools/magmap.py` 默认 `--mag-source raw`，输出的 `magmap.json` 带 `"magSource": "raw"`；
- App 导入这样的地图后，实时定位自动用同一种算法（开始后约 5 秒估好偏置，之前先用校准后磁场）。「传感器状态」里能看到「磁场来源」和估出来的偏置；
- 旧地图（没有 `magSource`）和 App 里按点位校准的地图仍然用校准后磁场。

在你的真实会话上：被丢掉的 448 个样本不用丢了，低置信度（会冻结）的时间从 13% 降到 0～3%，冷启动从 6.6 秒到 5.1 秒，精度不变（中位约 60 cm）。
**手机换了保护壳 / 磁吸配件，偏置会变**：实时这边每次重新估，不受影响；但建图的几次采集之间配件要一致。

## 8. 定位的显示规则

- 还没定准（冷启动）：不显示位置，提示「定位中」；
- 定准之后走到没采集的地方、或读数对不上：蓝点变灰、冻结在最后可信的位置，提示「定位丢失」；回到采集过的通道自动恢复；
- 已经定准时，位置不会一下跳出 3 m 以外，要连续多次证据才切换。

## 9. 现在推荐的完整流程（2026-10-06 更新）

1. **门店数据**页导入 `map.json`；**地磁 → 地图**页填「地图朝向」（例如 316）。
2. **采集**：开始建图采集 → 起点长按定点 → 设朝向 → 直走 1.5 m → 沿通道走（每条双向）。途中长按修正是**可选**的，软件会自动把轨迹贴到通道中心线上。可以同时打开「LiDAR 实景扫描」。
3. **采集**页下方「生成磁场图（手机上）」：勾选会话 → 「生成并启用」。不需要电脑。电脑上的 `tools/magmap.py` 仍可用来做质检。
4. **定位**：打开传感器 → 「自动定位」或长按定点 + 设朝向 → 走。「设置」里的开关默认就能用（视觉里程计开、地磁纠偏开）。
5. **导航**：在定位页「导航」里搜货架编号（例如 `Shelf-012`），沿通道规划路线，按转弯提示走。
6. **AR 校对**：定位或采集对齐后，右上角 **AR** 按钮，拖滑块让线框贴到实物，记录偏移。
7. **数据管理**：地图页里，统一查看 / 导出 / 删除会话、轨迹、网格、AR 记录。

同一时间只允许一个页面使用传感器：在一个页面开始，另一个页面正在跑的会自动停止（日志里有记录）。

## 房间扫描（小范围室内，例如酒店房间）

「房间扫描」页用 Apple RoomPlan（iPhone 16 Pro 的激光雷达）扫房间：

1. 填个房间名，点「开始扫描」，拿着手机慢慢绕房间走一圈，摄像头扫过每面墙、门窗和家具；点「扫完了」，几秒后出结果。
2. 结果有 **2D 平面图**（墙深色、门棕色、窗浅蓝、家具灰块带名字、地面浅蓝）和 **3D**（半透明墙、按真实高度的家具）。可以导出 3D 模型（USDZ，用「文件」/ 隔空投送打开就能看）和 2D 地图（JSON）。
3. 扫完**自动加进地图库并切换过去**。之后在「地磁定位」页照常建图采集、涂色、生成磁场图、定位：
   - 房间没有通道，**可走区域 = 地面 − 家具（四周放宽 15 cm）**，涂色范围就是这块；
   - 自动贴通道、通道走向先验在房间里不起作用（没有通道），轨迹靠 ARKit；
   - 扫描时房间被自动转正（墙横平竖直），所以地图「上方」不是北，地图朝向不填就行（定位用视觉里程计，不依赖罗盘）。

文件存在 `Documents/room-scans/room_<时间>/`：`map.json`（地图）、`room.usdz`（3D 模型）、`captured_room.json`（RoomPlan 原始结果）。

## 地图库（门店 / 房间切换）

「地磁定位」页顶上的「地图 ▾」菜单可以随时切换地图（例如「BQ 门店」「酒店 1203」）；「门店数据」页和「房间扫描」页有地图库列表，左滑改名、删除（在用的不能删）。

- 第一次打开新版时，现在的门店地图自动收进地图库（名字取地图里的楼层名，可以改成「BQ 门店」）。
- **每张地图有自己的工作区**：磁场图和点位、地图朝向、采集进度和涂色、磁场图来源说明。切换时自动收起 / 放回，不会互相覆盖。
- 建图采集会话记着地图编号；「生成磁场图」只列当前地图的会话（旧会话按地图尺寸判断）。
- 「门店数据」页导入地图文件 = 加进地图库一张新地图并切换过去；从服务器下载 = 更新当前这张。
- 正在采集或定位时不能切换。

房间里的定位和门店一样：切到房间地图 → 采集（沿房间涂色，把地面涂满）→ 生成磁场图 → 定位页「自动定位」或长按定点。房间没有通道，可走区域是地面减家具。
